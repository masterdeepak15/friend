# Writing a stand-up update

Use this when the owner asks for a stand-up, a daily update or a status line.

1. If they gave rough notes, use them. If not, ask one question: "What did you get done, what is next, and is anything blocking you?"
2. Write three short parts, each at most three bullets:
   - **Done**: finished work, in past tense, with the result ("Fixed the login redirect").
   - **Next**: what happens today, in order of importance.
   - **Blocked**: only real blockers, and who or what is needed. Write "Nothing" if there are none.
3. Keep every bullet under 15 words. No filler, no apologies.
4. Show the update on the screen as a card and read the **Done** and **Blocked** parts aloud in one or two sentences.
5. Offer to copy it to a file only if they ask.
